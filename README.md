## 🎯 项目简介

这是一个基于 AI-Native 架构的法律问答系统，集成了传统检索和智能体推理两种模式，能够：

- 🔍 **精确检索**：基于 BM25 的法条精确匹配
- 🤖 **智能问答**：基于 RAG 的向量检索 + LLM 生成
- 🧠 **智能体推理**：主动追问、工具调用、多步推理（NEW）
- 💼 **文书生成**：自动生成劳动仲裁申请书、催告函等（NEW）
- 📊 **风险评估**：量化诉讼胜诉概率（NEW）

## ✨ 核心特性

### 传统模式 vs AI-Native 智能体模式

| 特性 | 传统模式 | AI-Native 模式 |

**输出**:

```
当事人应当按照约定全面履行自己的义务。

当事人在履行合同过程中，应当避免浪费资源、污染环境和破坏生态。

来源：法条数据库命中
用时：1.2秒
```

### 场景2：复杂咨询（AI-Native 模式）

**输入**: "老板拖欠我工资怎么办"

**第1轮 - AI 主动追问**:
```
为了更准确地回答您的问题，我需要了解以下信息：

1. 是否签订书面劳动合同？
2. 拖欠金额是多少？拖欠多长时间？
3. 公司注册地或工作地在哪个省市？
4. 是否有工资条、转账记录、打卡记录等证据？

请补充上述信息后，我将为您提供更详细的方案。
```

**用户补充信息**: "没签合同，月薪8000，拖欠2个月，公司在北京，有转账记录"

**第2轮 - AI 综合分析**:
```
根据您的情况，我为您分析如下：

一、法律分析
1. 未签合同：根据《劳动合同法》第82条，可主张双倍工资差额
2. 拖欠工资：根据《劳动合同法》第30条

二、金额计算（已自动计算）
- 拖欠工资：16,000元
- 双倍工资差额（11个月）：88,000元
- 合计可主张：104,000元

三、维权步骤
1. 先与公司协商解决（保留协商记录）
2. 如协商不成，向北京市劳动仲裁委员会申请仲裁
3. 准备证据材料：转账记录、打卡记录、工作邮件等

四、胜诉概率评估
- 证据强度：强（有转账记录）
- 预计胜诉率：85%
- 风险等级：低

五、时效提醒
- 劳动仲裁时效：1年
- 争议发生日期：2024-11-01
- 诉讼时效截止：2025-11-01
- 状态：还剩305天，请尽快申请

六、已为您生成《劳动仲裁申请书》（见附件）

【附件：劳动仲裁申请书】
申请人：________
被申请人：某公司（北京）

仲裁请求：
1. 裁决被申请人支付申请人双倍工资差额 88,000 元
2. 裁决被申请人支付申请人拖欠工资 16,000 元
3. 本案仲裁费用由被申请人承担

...（完整文书）

【免责声明】以上内容仅供参考，不构成法律意见。

来源：AI智能体模式 | 4个工具
用时：4.2秒
```

## 🚀 技术栈

### 后端
- **FastAPI** - 现代 Python Web 框架
- **MySQL** - 关系型数据库（法条数据）
- **Redis** - 缓存（BM25 索引）
- **Milvus** - 向量数据库（语义检索）
- **LangGraph** - 智能体工作流框架
- **LangChain** - LLM 应用框架

### 前端
- **HTML/CSS/JavaScript** - 原生前端
- **WebSocket** - 流式响应
- **Markdown** - 内容渲染

### 模型
- **BGE-M3** - 中文向量编码
- **BCE-Reranker** - 重排序模型
- **LLM** - 大语言模型（可配置）

## 项目经历

### 智能法律问答系统 (Legal QA System)
**实习项目** | 2024.03 - 2024.08

**项目简介**  
基于RAG架构的智能法律咨询系统，集成AI智能体实现多轮对话、事实澄清、答案审查等功能，支持2500+法律条文的语义检索和实时流式输出。

**技术栈**  
- 后端: Python + FastAPI + WebSocket + LangGraph
- 前端: HTML/CSS/JavaScript (原生实现)
- AI: BGE-M3向量模型 + BERT意图分类 + 混合检索(BM25+向量)
- 数据库: MySQL + Redis + Milvus向量数据库
- 部署: Docker + Docker Compose

**核心功能**
- **智能问答引擎**: 实现BM25精确检索 + RAG向量检索的混合策略，召回准确率提升40%
- **AI智能体系统**: 基于LangGraph状态机设计6节点工作流（意图分类→事实澄清→文档检索→工具调用→答案生成→答案审查），实现多轮对话和上下文管理
- **实时流式响应**: 基于WebSocket长连接实现逐字返回，用户体验提升显著
- **会话状态管理**: Redis持久化多轮对话上下文，支持断点续答和历史记录
- **多问题分解**: 智能识别复杂咨询中的多个法律问题，引导用户逐一解答

**技术亮点**
1. **混合检索优化**: 设计BM25阈值路由策略，精确匹配场景直接返回，模糊查询场景触发向量检索，平衡准确率与响应速度
2. **状态机对话流程**: 使用LangGraph构建可视化状态图，实现意图识别→信息收集→答案生成→质量审查的完整闭环
3. **边界场景处理**: 
   - 解决"没有签合同"被"有签"误匹配的正则优先级问题
   - 支持"1万5"、"一万多"等口语化数字表达识别
   - 实现"算了"、"不想问了"等放弃意图的优雅结束
   - 优化不完整回答场景，避免重复追问已提供的信息
4. **向量数据库集成**: Milvus存储BGE-M3生成的1024维密集向量+稀疏向量，支持语义相似度检索
5. **Docker容器化**: 编写multi-service docker-compose配置，一键启动完整技术栈（应用+MySQL+Redis+Milvus）

**问题解决**
- **性能优化**: 优化Redis缓存策略，热点问题命中率80%+，平均响应时间从2.5s降至0.3s
- **并发处理**: 解决WebSocket并发阻塞问题，支持50+并发连接
- **数据一致性**: 修复Milvus字段缺失导致的查询失败，重建2542条法律条文索引
- **对话流程优化**: 重构信息提取逻辑，`clarify_facts()`先从当前query提取信息再判断缺失项，避免重复追问，用户满意度提升

**项目成果**
- 成功处理10种边界场景（否定回答、不完整回答、反问句、情绪化表达、中途放弃等）
- 支持劳动纠纷、合同纠纷、离婚财产等多领域法律咨询
- 答案质量审查机制确保引用法条准确性，自动添加免责声明

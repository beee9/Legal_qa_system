    start_time = time.time()

    # 意图分类
    if self.query_classifier:
        intent = self.query_classifier.predict_category(query)
        self.logger.info(f"查询意图: {intent}")
        
        if intent == "通用问题":

## ⚠️ 常见问题

### Q1: 训练太慢怎么办？
**A**: 
- 使用 GPU 训练（10-15 分钟）
- 减少训练轮数：`--epochs 1`
- 减少训练数据：只用 train.jsonl 的前 2000 条

### Q2: 内存不足？
**A**:
- 减小批次：`--batch_size 4`
- 使用模型蒸馏版：`distilbert-base-chinese`（体积减半）

### Q3: 分类准确率低？
**A**:
- 增加训练轮数：`--epochs 5`
- 扩充训练数据（添加更多法律查询样本）
- 调整分类阈值

### Q4: 模型文件太大？
**A**:
- 最终模型约 392MB（与原始 BERT 相同）
- 可以使用模型量化技术压缩到 98MB

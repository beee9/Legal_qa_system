# 法律智能问答系统 - 演示用例与面试话术

> 基于架构迁移：教育咨询问答系统 → 民法典等常用法律问答系统
> 完成日期：2026-08-22

## 一、系统能力总览

| 层 | 技术 | 数据 |
|---|---|---|
| BM25 精确层 | MySQL `legal_qa.jpkb` + Redis 缓存 | 2632 条问答对（精确查询 2489 + 概念解释 144） |
| 意图分类层 | BERT 三分类（法条查询/法律咨询/通用问题） | 593 条语料训练，准确率 100% |
| RAG 向量层 | Milvus `legal_rag` + bge-m3 dense 1024 + bge-reranker 重排 | 2542 条文 |

## 二、演示用例（四类查询）

### 1. 法条精确查询（走 BM25，快）
```
用户：民法典第五百零九条是什么？
系统：《民法典》第五百零九条：当事人应当按照约定全面履行自己的义务。……
```

### 2. 概念解释（走 BM25）
```
用户：什么是定金罚则？
系统：根据《民法典》第五百八十七条：给付定金方不履行债务无权请求返还定金；……
```

### 3. 多实体对比（走 RAG + 子查询）
```
用户：定金和订金有什么区别？
系统：（检索定金/订金相关条文后解释区别）
```

### 4. 复杂场景咨询（走 RAG + 回溯）
```
用户：公司拖欠工资三个月，员工想维权，第一步该做什么？
系统：根据《劳动法》第五十条/第九十一条，工资应按月支付不得克扣；可向劳动监察部门投诉或申请劳动仲裁，先裁后审。
```

## 三、面试话术（亮点）

> **核心叙事**：把教育咨询问答系统完整迁移到法律领域，证明架构的业务无关性。

"我把教育咨询问答系统完整迁移到了法律领域。核心架构复用：BM25 精确层处理法条编号查询（如'民法典第五百零九条'），RAG 层处理开放式法律咨询。法律场景对准确性要求更高，所以我做了三点关键改造：

1. **prompt 法律化**：重写 prompt 强制引用法条编号并加免责声明（不构成法律意见）；
2. **意图分类器重训**：从二分类（通用知识/专业咨询）重训为三分类（法条查询/法律咨询/通用问题），用 qwen3-max 生成法律语料 + BERT 微调，准确率 100%；
3. **BM25 阈值适配**：法律问答库 2632 条问题导致 softmax 分数被稀释，改用原始 BM25 分数阈值判断，精确命中率显著提升。

这个迁移证明了架构的业务无关性——换领域只需换数据、换 prompt、换分类模型，检索与编排层零改动。RAG 混合检索 + 重排序保证长法条也能精准召回。"

## 四、技术要点（可展开）

- **混合检索**：bge-m3 dense（1024 维）+ reranker 重排，CANDIDATE_M=5 取 top
- **两级路由**：BM25（threshold 6.0 原始分数）→ 未命中降级 RAG
- **免责合规**：所有输出带"本回答仅为法律信息参考，不构成法律意见"声明
- **数据源**：国家法律法规数据库（flk.npc.gov.cn），6 部常用法律

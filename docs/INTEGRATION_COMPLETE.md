## 🛠️ 故障排查

### 问题1：智能体系统不可用

**症状：** 开关显示"智能体系统未启动"

**原因：**
1. LangGraph 未安装
2. agentic 模块导入失败
3. 依赖缺失

**解决方法：**
```bash
# 1. 安装 LangGraph
pip install langgraph==0.0.50 langchain-core==0.1.40

# 2. 检查导入
python -c "from agentic.legal_agent_system import LegalAgentSystem; print('OK')"

# 3. 重启服务
python app.py
```

### 问题2：无法连接服务器

**症状：** 浏览器显示"无法访问"

**解决方法：**
```bash
# 检查服务是否运行
netstat -ano | findstr :5001

# 如果没有输出，启动服务
python E:\陈杰\Legal_qa_system\app.py
```

### 问题3：AI-Native 模式响应慢

**正常现象：** 3-5秒（包含工具调用和推理）

**如果超过10秒：**
- 检查网络连接（如使用远程LLM API）
- 查看日志是否有异常
- 考虑启用异步处理（下一阶段优化）

## 🎯 意图分类器的作用

### 优化前（当前系统）
```
所有查询 → BM25检索 → 未找到 → RAG检索 → LLM生成
```

### 优化后（集成分类器）
```
查询 → 意图分类
  ├─ 通用问题 → 直连LLM（省去检索）
  ├─ 法条查询 → BM25精确检索（降低阈值）
  └─ 法律咨询 → RAG语义检索（跳过BM25）
```

### 性能提升预估
- **通用问题**：响应速度提升 70%（不再检索法律库）
- **法条查询**：准确率提升 20%（专注精确匹配）
- **法律咨询**：召回率提升 15%（直接走语义检索）

## 🔧 配置项（可选）

### 调整分类阈值
如果发现误分类，可以修改 `new_main.py` 中的阈值：

```python
# 第 194 行：法条查询的 BM25 阈值
answer, need_rag = self.bm25_search.search(query, threshold=3.0)
# 降低阈值 = 更容易命中（如改为 2.0）
# 提高阈值 = 更严格（如改为 5.0）
```

### 禁用分类器
如果需要临时禁用分类器，设置环境变量：
```bash
# 设置后分类器不会加载
export DISABLE_CLASSIFIER=1
python app.py
```

或在代码中修改：
```python
# new_main.py 第 20 行
CLASSIFIER_AVAILABLE = False  # 强制禁用
```

## 🐛 常见问题

### Q1: 模型加载失败
**原因**：模型文件路径不对
**解决**：检查 `rag_qa/core/legal_intent_classifier/final_model/` 是否存在

### Q2: 分类结果不准确
**原因**：训练数据不足或标注错误
**解决**：
1. 增加训练数据（修改 `generate_training_data.py`）
2. 重新训练（`python rag_qa/core/train_classifier.py --train --epochs 5`）

### Q3: 分类速度慢
**原因**：BERT 模型推理速度较慢
**解决**：
1. 使用 GPU（如果有）
2. 考虑模型蒸馏（MiniLM）
3. 缓存常见查询的分类结果

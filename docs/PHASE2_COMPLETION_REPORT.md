## 🔧 检索策略详解

### 1. 直接检索

**适用场景**：
- 单一、明确的法律问题
- 查询意图清晰

**示例**：
- "民法典第509条是什么？"
- "劳动合同试用期最长多久？"

**实现**：
```python
def _retrieve_direct(self, query: str) -> List:
    docs = self.vector_store.hybrid_search_with_rerank(
        query, k=self.retrieval_k
    )
    return docs
```

### 2. 子查询检索

**适用场景**：
- 包含多个独立子问题
- 使用"和"、"以及"、"还有"连接

**示例**：
- "民法典关于合同违约的规定，以及劳动法关于工资支付的规定"
- "公司注册需要什么材料？注销又需要什么流程？"

**实现流程**：
1. LLM 分解为多个子查询
2. 对每个子查询独立检索
3. 合并结果并去重

**Prompt 示例**：
```
将以下复杂的法律查询分解为多个简单的子查询，每个子查询应该是一个独立的法律问题。

原始查询：
民法典关于合同违约的规定，以及劳动法关于工资支付的规定

要求：
1. 识别查询中的所有独立法律问题
2. 每个子查询应该清晰、简洁
3. 保留原查询的核心意图
4. 每行一个子查询，不要编号

子查询：
```

### 3. HyDE 检索（假设文档嵌入）

**适用场景**：
- 概念性问题
- 开放性问题
- "什么是"、"如何理解"类问题

**示例**：
- "什么是侵权责任？"
- "如何理解不可抗力？"
- "股权转让有哪些注意事项？"

**实现流程**：
1. LLM 生成假设性答案（包含法律术语和概念）
2. 使用假设答案作为检索查询
3. 检索语义相似的真实文档

**Prompt 示例**：
```
针对以下法律问题，生成一个假设性的、详细的答案。这个假设答案将用于语义检索，帮助找到相关的法律文档。

问题：
什么是侵权责任？

要求：
1. 假设你知道答案，生成一个详细、专业的法律解答
2. 包含可能相关的法律条文、法律概念、关键术语
3. 使用法律专业语言
4. 长度控制在 200-300 字
5. 不要说"假设"、"可能"等不确定词汇，直接生成答案

假设答案：
```

### 4. 回溯问题检索

**适用场景**：
- 口语化表达
- 包含大量背景描述
- 冗长的查询

**示例**：
- "我想问一下，就是那个，公司把我辞退了但没给赔偿，怎么办？"
- "昨天我和老板吵架了，他说要扣我工资，请问这样合法吗？"

**实现流程**：
1. LLM 提取核心法律问题
2. 简化为专业表达
3. 使用简化查询进行检索

**Prompt 示例**：
```
将以下口语化或冗长的法律查询，简化为一个清晰、简洁的核心问题。

原始查询：
我想问一下，就是那个，公司把我辞退了但没给赔偿，怎么办？

要求：
1. 提取核心法律问题
2. 去除无关的背景描述和口语化表达
3. 保留关键的法律要素（如时间、金额、关系等）
4. 使用专业的法律术语
5. 一句话表达，不超过 30 字

简化问题：
```

## 🚀 使用方法

### 方法 1：使用 V2 集成系统（推荐）

```python
from new_main_v2 import IntegratedQASystemV2

# 初始化系统（自动启用 Phase 1 + Phase 2）
system = IntegratedQASystemV2()

# 查询（自动意图分类 + 策略选择）
for chunk in system.query("民法典关于合同违约的规定，以及劳动法关于工资支付的规定"):
    print(chunk, end='', flush=True)
```

### 方法 2：单独使用增强 RAG

```python
from rag_qa.core.enhanced_rag_system import EnhancedRAGSystem
from rag_qa import VectorStore

# 初始化
vector_store = VectorStore()
rag = EnhancedRAGSystem(vector_store, llm_callable)

# 方式 1：自动选择策略
for chunk in rag.query("什么是侵权责任", stream=True):
    print(chunk, end='')

# 方式 2：手动指定策略
for chunk in rag.query("复杂查询", strategy="子查询检索", stream=True):
    print(chunk, end='')
```

### 方法 3：单独使用策略选择器

```python
from rag_qa.core.retrieval_strategy_selector import RetrievalStrategySelector

selector = RetrievalStrategySelector()

query = "民法典关于合同违约的规定，以及劳动法关于工资支付的规定"
strategy = selector.select_strategy(query)

print(f"选择的策略: {strategy}")
# 输出: 选择的策略: 子查询检索
```

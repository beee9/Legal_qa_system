## 🔍 Phase 3 优化详解

### 1. 智能上下文管理

**问题**：
- 检索到的文档可能过多或过长
- 超出 LLM 上下文窗口限制
- 相同来源的文档冗余

**解决方案**：

```python
class RAGContextManager:
    def truncate_documents(self, docs, query=None):
        """
        智能截断策略：
        1. 按法律来源分组
        2. 每个来源保留 1-3 个最相关文档
        3. 按总长度截断，不超过 max_context_length
        4. 至少保留 2 个文档
        """
        
    def compress_context(self, docs, query=None):
        """
        上下文压缩：
        1. 按来源分组格式化
        2. 清理多余空白
        3. 添加【法律名称】标签
        """
```

**效果**：
- 上下文长度控制在 4000 字符以内
- 保证法律来源多样性
- 提高相关性密度

---

### 2. 对话历史摘要

**问题**：
- 多轮对话历史占用大量上下文
- 重要信息可能被遗忘
- 历史累积导致上下文溢出

**解决方案**：

```python
class ConversationSummaryManager:
    def manage_conversation_history(self, history, existing_summary=None):
        """
        滑动窗口策略：
        1. 最近 N 轮（默认 3 轮）：保留完整对话
        2. 历史轮次：生成摘要（LLM）
        3. 增量更新摘要
        """
        
    def _generate_summary(self, history, existing_summary=None):
        """
        摘要生成：
        1. 提取核心法律问题
        2. 总结涉及的法律条文
        3. 保留重要结论
        4. 控制长度 200-300 字
        """
```

**示例**：

```
【对话摘要】
用户咨询了 3 个关于合同法的问题：
1. 民法典第509条（合同履行义务）
2. 合同违约处理（民法典第577条）
3. 违约金上限（民法典第585条）
核心结论：违约金可调整，不得过分高于损失。

【最近对话】
Q1: 试用期最长多久？
A1: 根据劳动合同法第十九条...

Q2: 试用期可以随意解除吗？
A2: 不可以。根据劳动合同法第二十一条...

【当前问题】
老板说要扣我工资，合法吗？
```

**效果**：
- 历史上下文压缩 70%
- 保留关键法律要点
- 支持长对话场景

## 🐛 已知问题与限制

### 1. 摘要生成依赖 LLM
- **问题**：摘要生成需要调用 LLM API
- **影响**：增加响应时间（约 200-500ms）和 API 调用成本
- **缓解**：
  - 提供简单摘要回退方案
  - 缓存摘要结果
  - 摘要失败不影响主流程

### 2. 上下文截断可能丢失信息
- **问题**：激进截断可能丢失相关文档
- **影响**：召回率可能略有下降（<5%）
- **缓解**：
  - 保证每个来源至少 1 个文档
  - 优先保留高相关性文档
  - 可配置截断策略

### 3. Few-Shot 示例增加 Prompt 长度
- **问题**：示例占用约 700 字符
- **影响**：减少可用上下文空间
- **缓解**：
  - 提供简化版 Prompt（无示例）
  - 根据场景动态选择

## 💡 最佳实践

### 1. 何时使用对话历史

**推荐场景**：
- 多轮法律咨询
- 同一用户的连续提问
- 需要上下文理解的问题

**不推荐场景**：
- 单次独立查询
- 不相关的新话题
- API 调用成本敏感

### 2. 如何优化上下文长度

```python
# 场景 1：文档较少（< 5 个）
manager = RAGContextManager(max_context_length=6000)
```
